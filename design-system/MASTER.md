## 2. Typography System

### Font Pairing
* **Display / Headings**: `Plus Jakarta Sans`, system-ui, sans-serif
  * Weight: `700 (Bold)`, `800 (ExtraBold)`
  * Editorial Tracking: `-0.03em` for headers, crisp modern Gen-Z energy.
* **Body / UI Elements**: `Inter`, system-ui, sans-serif
  * Weight: `400 (Regular)`, `500 (Medium)`, `600 (SemiBold)`
  * Body Line Height: `1.6` for effortless readability.

### Typographic Hierarchy
* `Hero Display`: `clamp(2.75rem, 5.5vw, 4.25rem)` / line-height `1.08`
* `Section Heading`: `clamp(2rem, 3.5vw, 2.75rem)` / line-height `1.15`
* `Card Heading`: `1.25rem (20px)` / line-height `1.3`
* `Body Lead`: `1.125rem (18px)` / line-height `1.6`
* `Body Regular`: `1.0rem (16px)` (Minimum 16px to prevent iOS auto-zoom)
* `Caption / Micro-tag`: `0.8125rem (13px)` / uppercase / letter-spacing `+0.05em`
